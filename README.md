>

## **🛠 기술 스택**

- **Language:** **`JavaScript`**, **`TypeScript`**
- **Library:** **`React`**, **`Zustand`**, **`Axios`**, **`MUI(Material-UI)`**, **`Recharts`**, **`FullCalendar`**
- **Infra:** **`Google Cloud Platform`**
- **CI / CD:** **`Docker`**, **`GitHub Actions`**
- **협업:** **`Git`**, **`GitHub`**, **`Postman`**, **`Figma`**, **`Notion`**, **`Slack`**, **`Jira`**

## 📌 주요 구현 기능

- 캘린더와 통계 차트의 “월” 상태를 전역으로 동기화해 화면 간 데이터 불일치 방지
- 월 이동 시 캘린더/차트가 같은 기준으로 즉시 갱신되는 탐색 흐름 구성
- 전역 상태 구독 범위를 조정해 불필요 렌더링을 줄이고 화면 반응성 개선

## 🔧 구현 상세

- 월(캘린더) 기준 전역 상태로 화면 간 월 정보 일관성 확보
- 월 이동 이벤트 → 상태 갱신 → 차트 재렌더링으로 단방향 갱신 흐름 구성
- 로컬 상태 분산을 줄이고 전역 상태를 기준으로 데이터 흐름/디버깅 포인트 단순화

## 🐞 프로젝트 이슈 & 해결 과정

- 캘린더의 로컬 상태 기반 월 관리로 인한 통계 화면의 이전 월 데이터 잔존 문제
- 월 변경 이벤트의 다른 페이지 미전달에 따른 상태 동기화 실패 원인
- 월 상태의 Zustand 스토어 승격 및 구독 범위 구체화를 통한 필요한 컴포넌트 중심 재렌더링 구조 개선
- 월 이동 즉시 차트 업데이트 및 렌더링 프로파일 기준 15% 지연 제거 결과
